# Changelog

All notable public-preview changes are recorded here.

## 0.1.0 - 2026-09-13

- Added the local React/Node/SQLite operator control plane.
- Added exact-scope policy, expiring human approvals, budgets, emergency stop,
  audit chaining, sealed evidence, reviewed findings and deterministic reports.
- Added the zero-target guided demo and synthetic Blue Team validation paths.
- Added append-only remediation, separately approved retests, comparison and
  two-stage source plus rendered-output report QA.
- Added the retained operational benchmark and verified backup/restore flow.
- Added Windows sensor identity and bounded proof components while keeping
  continuous collection, remote transport and action authority disabled.
- Refreshed the locked dependency graph; `npm audit` reports zero known
  vulnerabilities at release preparation.
- Made generated build paths independent of the repository's checkout depth.
- Published as an Apache-2.0 engineering preview for evaluation and feedback.
