# Community Code of Conduct

Be respectful, specific and safety-conscious. Welcome questions from learners,
assume good faith and critique ideas or code rather than people.

Harassment, discrimination, threats, doxxing, credential sharing, publication
of private evidence, or encouragement of unauthorized testing are not accepted.
Maintainers may edit or remove content, close contributions or restrict
participation when needed to protect people or the project's safety boundary.

Report conduct concerns privately through the repository owner's GitHub profile.
